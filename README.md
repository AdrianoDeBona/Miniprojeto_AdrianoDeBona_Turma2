Objetivo

Este repositório contém o desenvolvimento e análise de uma base de dados do setor de varejo. O objetivo é transformar em uma base de dados limpa e padronizada para análise.

Ferramentas e Tecnologias Utilizadas

• VS Code • Python • Pandas & NumPy • Git & GitHub

Etapas do Projeto

• Importação da plataforma Kaggle e análise dos dados • Aplicação de processos de limpeza de dados • Aplicação de funções de transformação e padronização de dados • Desenvolvimento de script em Python para coleta de estatísticas • Construção de relatórios e envio de arquivos

Conclusão

Com base na análise realizada, pude constar que existem valores nulos em um determinado produto. Optei por mante-lo na base de dados como "Sem categoria" por se tratar de um produto com identificação mas sem categoria ou descrição. Além disso encontrei diversos produtos com codigo de identificação duplicado, optei por mante-los por ter entendido que se tratam de produtos de mesmo nome mas que podem existir variedades ou marcas diferentes.
